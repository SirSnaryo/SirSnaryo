## About

Independent developer, mostly in the Minecraft ecosystem. I write the plugins, set up the servers, and build the bits around them — storefronts, dashboards, bots, and the small scripts that save someone an hour a week.

- **Minecraft plugins** — Java, built for Paper, Spigot, and Purpur. Config-first: everything adjustable, nothing hardcoded.
- **Discord bots** — JavaScript and TypeScript, from utility bots to server tooling.
- **Web** — TypeScript front ends, Supabase and MySQL behind them, Cloudflare and Netlify in front.
- **Small programs** — Python when a job just needs doing.

I care about the unglamorous parts: clean configs, sane defaults, and updates that don't break someone's server.

**Right now:** maintaining my plugins on Modrinth, adding to a survival world that's still on its first map, and building for [Raven MC](https://raven-mc.net).
